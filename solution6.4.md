I built a webpage with multiple scrollable sections to demonstrate different positioning techniques. First, I created a navigation bar at the top and applied position sticky with top 0 and a high z-index of 1000, which keeps the navbar fixed at the top of the viewport while scrolling through the page, unlike fixed which would be removed from document flow, sticky still occupies space until it sticks. For the floating contact or help button, I used position fixed with bottom 20px and right 20px and z-index 9999, which keeps the button fixed relative to the browser window at all times, so it remains visible even when scrolling to the bottom of the page. Inside the cards, I demonstrated absolute positioning by placing a badge like NEW, 50% OFF, and HOT inside each card; to make this work, I set position relative on the parent card element, which creates a positioning context, and then set position absolute on the badge with top -10px and right -10px, allowing the badge to be placed precisely at the corner of the card overlapping its border. Finally, I used z-index to control the stacking order of overlapping elements, giving the sticky navbar z-index 1000 so it stays above sections, badges z-index 10 to 30 so they appear above cards, and the floating button z-index 9999 so it stays on top of everything including the navbar.
